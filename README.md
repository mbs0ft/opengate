# opengate
[English] | [Русский](README.ru.md)

**wip – testing needed!**  

a tweak for the legacy VK iOS app that redirects VK API requests to OpenVK instances

## testing
this is a very early build of the tweak. **tested on VK 2.15.3.** other versions have not been tested yet. please open an issue to report which versions are working

## feature status

### what's working:
- my profile
- friends feed
- messages (**via the "new message" button**)
- friends tab
- communities tab
- photos
- music
- making posts

### what's not working (needs fixing):
- global feed
- fetching dialogues
- videos tab
- uploading photos in new posts

## installation
1. download the latest release from the releases section
2. install via Sileo or inject the tweak into the app
