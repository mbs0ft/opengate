# opengate
[English](README.md) | [Русский]

**WIP – требуется тестирование!**  

твик для старого iOS-приложения VK, который перенаправляет запросы к API VK на инстансы OpenVK

## тестирование
это самая ранняя сборка твика. **проверено на VK 2.15.3.** другие версии пока не тестировались. пожалуйста, создайте issue, если у вас заработает какая-то другая версия

## статус функций

### что работает:
- мой профиль
- лента друзей
- сообщения (**через кнопку «новое сообщение»**)
- вкладка друзей
- вкладка сообществ
- фотографии
- музыка

### что не работает (требуется исправление):
- глобальная лента
- загрузка диалогов
- вкладка видео

## установка
1. скачайте последний релиз из раздела релизов
2. установите через Sileo или внедрите твик прямо в приложение
